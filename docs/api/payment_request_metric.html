Fields

Field Type Required Description

load

GET /api/v1/paymentrequests/metrics

Operation ID: GetPaymentRequestMetricsForMerchant.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | merchantID | query | string (uuid) | No | The merchant ID to get the payment request metrics. This field is ignored for merchant tokens and required for user tokens. | | fromDate | query | string (date-time) | No | The date filter to apply to retrieve payment request metrics created after this date. | | toDate | query | string (date-time) | No | The date filter to apply to retrieve payment request metrics created up until this date. | | search | query | string | No | The text filter to apply to retrieve payment requests with a similar title, description or contact information.k | | currency | query | enum: NONE, GBP, EUR, USD, AUD, BGN, ... | No | The currency filter to apply to retrieve payment request metrics with this currency. | | minAmount | query | number (double) | No | The amount filter to apply to retrieve payment request metrics that exceed this amount. | | maxAmount | query | number (double) | No | The amount filter to apply to retrieve payment request metrics that don't exceed this amount. | | tags | query | array of string (uuid) | No | The tag filter to apply to retrieve payment request metrics with at least one of these tags. | | paymentMethods | query | array of enum: None, card, pisp, lightning, cardtoken, applePay, ... | No | The payment method filter to apply to retrieve payment request metrics with any of these payment methods. | | includeArchived | query | boolean | No | Flag that indicates whether to include archived payment requests or not. |
