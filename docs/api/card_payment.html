POST /api/v1/paymentrequests/{id}/card/refund/{partialRefundAmount}

Operation ID: RefundCardPayment.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string (uuid) | Yes | The ID of the payment request a card payment has previously been captured for. | | partialRefundAmount | path | number (double) | Yes | The partial amount to be refunded in case of captured payment. |

Request body

multipart/form-data

Property Type Required Description
authorizationID string No The authorisation ID of the card payment to refund.

Responses

200: Returns a card payment response model that indicates the result of the refund payment attempt

application/json

payerAuthenticationWindowWidth integer (int32) No If a card payment response indicates a 3-D Secure payer authentication is required this field holds the requested width of the iframe used to hold the challenge.
paymentRequestCallbackUrl string No The callback URL that was set when the payment request was created. Payers will be redirected to this URL after a successful card authorisation.
paymentRequestID string (uuid) No
requestID string No
responseCode string No
responseType enum: None, CardPayerAuthenticationSetupResponse, CardPaymentResponse, PaymentInitiationResponse No
status string No

POST /api/v1/paymentrequests/{id}/card/paywithtoken

Operation ID: SubmitTokenisedCardPayment.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string (uuid) | Yes | The ID of the payment request the card payment is being submitted for. |

Request body

multipart/form-data

Property Type Required Description
CardSecurityCode string No Not used for merchant initiated transactions. Optional for customer initiated transactions. If supplied will be sent to the card processor as a check that the customer using the tokenised card knows the card verification number.
PartialAmount number (double) No Optional partial payment amount. If not specified then the full payment request amount will be attempted.
PaymentInitiator enum: customer, merchant No Indicates who initiated the card token payment, customer or merchant.
TokenisedCardID string (uuid) No The ID of the tokenised card to use for the payment. The merchant needs to ensure that the use of the tokenised card is restricted to the same customer that created it.
