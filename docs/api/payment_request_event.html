list

GET /api/v1/paymentrequests/{id}/events

Operation ID: GetPaymentRequestEvents.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string (uuid) | Yes | ID of the payment request to get the events for. |

Responses

200: Returns a list of payment request event records
