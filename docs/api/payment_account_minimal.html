list

GET /api/v1/accounts/minimal

Operation ID: GetAccountsMinimal.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | merchantID | query | string (uuid) | No | The merchantID of the accounts to retrieve. | | currency | query | array of enum: NONE, GBP, EUR, USD, AUD, BGN, ... | No | Optional. Array. If specified will only return accounts for these currencies. | | connectedAccounts | query | boolean | No | Optional include connected accounts along with payment accounts. | | pageNumber | query | integer (int32) | No | Optional. The page number to retrieve. | | pageSize | query | integer (int32) | No | Optional. The number of accounts per page. | | search | query | string | No | The text filter to apply to retrieve accounts with a similar account name, IBAN etc. | | sort | query | string | No | Optional expression to sort the order of the accounts. Example "AvailableBalance desc,Inserted asc". | | onlyConnectAccounts | query | boolean | No | Only return connected accounts | | onlyArchived | query | boolean | No | Flag that indicates whether to fetch only archived accounts or not. | | includeArchived | query | boolean | No | Flag that indicates whether to fetch archived accounts or not. |

Responses

200: Returns the list of accounts for the merchant
