list

GET /api/v1/mandates

Operation ID: GetMandatesPaged.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | merchantID | query | string (uuid) | No | ID of the merchant to retrieve mandates for. | | page | query | integer (int32) | No | The page number from where records are retrieved. Note that the paging starts from page 1. If a 0 is supplied it will be treated as a 1 and the first page is returned. | | size | query | integer (int32) | No | The number of records to be retrieved from a page. | | fromDate | query | string (date-time) | No | The date filter to apply to retrieve mandates created after this date. | | toDate | query | string (date-time) | No | The date filter to apply to retrieve mandates created up until this date. | | status | query | enum: Unknown, Pending, Active, Expired, Failed | No | The status filter to apply to retrieve mandates with this status | | search | query | string | No | The text filter to apply to retrieve mandates with similar customer, bank account or mandate information. | | currency | query | enum: NONE, GBP, EUR, USD, AUD, BGN, ... | No | The currency filter to apply to retrieve mandates with this currency. | | minAmount | query | number (double) | No | The amount filter to apply to retrieve mandates that exceed this amount. | | maxAmount | query | number (double) | No | The amount filter to apply to retrieve mandates that don't exceed this amount. | | mandateIDs | query | array of string (uuid) | No | Optional list of mandate IDs to filter by. When supplied, only mandates whose ID is in this list are returned. | | sort | query | string | No | Optional expression to sort the order of the mandates. Example "Amount desc,Inserted asc". |

Responses

200: Mandate collection paged result
