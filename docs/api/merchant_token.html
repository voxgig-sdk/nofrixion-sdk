create

POST /api/v1/tokens

Operation ID: CreateMerchantToken.

Authentication: API key in the header (Bearer).

Request body

application/json

Property Type Required Description
description string Yes Token description
hmacAlgorithm enum: None, HMAC_SHA1, HMAC_SHA256, HMAC_SHA384, HMAC_SHA512 No Optional shared secret algorithm to use for HMAC authentication. If set a shared secret will be returned when the token is intially created but not on any subsequent retrievals.
ipAddressWhitelist string No Optional. If set represents a comma separated list of IP addresses that this token is authorised to be used from. Attempts to use the token from an IP address not in the list will be rejected.
merchantID string (uuid) Yes The merchant id to add to the token
permissionTypes array of enum: Deny, CreatePaymentRequest, EditPaymentRequest, DeletePaymentRequest, CreateRule, EditRule, ... No The list of permissions tho grant to the merchant token.
