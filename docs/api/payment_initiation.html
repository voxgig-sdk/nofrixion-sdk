create

POST /api/v1/paymentrequests/{id}/pisp

Operation ID: SubmitPayByBank.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string (uuid) | Yes | The ID of the payment request the payment initiation is being submitted for. |

Request body

multipart/form-data

Property Type Required Description
OriginUrl string No Optional. If set should indicate the origin URL the payer is making the payment from. If a pay by bank attempt fails and the payment request does not have a FailureCallbackUrl set then the payer will be redirected to this URL.
PartialAmount number (double) No Optional. If 0 the full amount is assumed.
ProviderID string Yes This is the ID of the institution (bank) that the payer ha chosen.
RedirectToOriginUrl string No

200: Returns a payment initiation response that contains the payment ID and the payment link
