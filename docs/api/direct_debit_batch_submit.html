Fields

Field Type Required Description
failedSubmissions object No Dictionary of failed submissions, keyed by the index (1-based) in the original request.
successfulSubmissions array No List of successfully submitted direct debit payments.

create

POST /api/v1/paymentrequests/directdebit/batchsubmit

Operation ID: BatchSubmitDirectDebit.

Authentication: API key in the header (Bearer).

Request body

application/json

Property Type Required Description
[].mandateID string (uuid) Yes The ID of the Direct Debit mandate to use for this payment.
[].paymentRequestID string (uuid) Yes The ID of the payment request to submit for direct debit.
[].submitAfter string (date-time) No Optional. Defines when this payment should be earliest submitted to the customer's bank account. If not specified, payments will be submitted as soon as possible.

Responses

200: A DirectDebitBatchSubmitResponse

application/json

Property Type Required Description
failedSubmissions object No Dictionary of failed submissions, keyed by the index (1-based) in the original request.
successfulSubmissions array of object No List of successfully submitted direct debit payments.
successfulSubmissions[].paymentRequestID string (uuid) No The ID of the payment request that was successfully submitted.
