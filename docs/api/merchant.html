Operation ID: GetChildMerchantsByParent.

Authentication: API key in the header (Bearer).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | merchantID | path | string (uuid) | Yes | The unique identifier of the parent merchant. | | pageNumber | query | integer (int32) | No | The page number to retrieve. | | pageSize | query | integer (int32) | No | The number of child merchants to return per page. | | search | query | string | No | A text filter to find child merchants by fields like name or ID. | | sort | query | string | No | A sort expression to order the results. 200: Returns the paged list of child merchants successfully
